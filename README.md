## Featured project

### [CDMX Flood Monitoring & Geographic Risk Assessment](https://github.com/aleemireyhdz-star/TT2)

A team-built academic IoT prototype connecting a 4–20 mA water-level sensor, ESP32 acquisition, SD logging and a Flask dashboard with geographic risk scoring.

**My contribution:** mechanical support design and calculations; electronic and power integration; initial acquisition firmware, later developed collaboratively; prototype assembly and staged hardware checks. The project README distinguishes these contributions from my teammates' backend/ML and solar-tracker work.

The repository includes prototype photographs, bilingual documentation, a local software demonstration and post-defense Python/JavaScript regression checks. The original physical prototype was dismantled after its defense.
