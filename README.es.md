# Emiliano Reyes

**Embedded / IoT · Integración de hardware y software**

[English](README.md) | Español

Egresado de Ingeniería Mecatrónica de UPIITA–IPN, enfocado en sistemas embebidos y en la integración de sensores, electrónica y software.

Mi trabajo académico incluye adquisición de señales con ESP32, integración electrónica y de alimentación, CAD, montaje de prototipos y pruebas manuales de hardware. Utilizo Python junto con el desarrollo embebido para conectar las mediciones con herramientas de software.

## Proyecto destacado

### [Monitoreo de inundaciones y evaluación de riesgo geográfico en CDMX](https://github.com/aleemireyhdz-star/TT2/blob/master/README.es.md)

Prototipo académico IoT desarrollado en equipo que conecta un sensor de nivel de agua de 4–20 mA, adquisición con ESP32, registro SD y una interfaz Flask con evaluación de riesgo geográfico.

**Mi contribución:** diseño y cálculos del soporte mecánico; integración electrónica y de alimentación; firmware inicial de adquisición, desarrollado después de forma colaborativa; montaje del prototipo y comprobaciones de hardware por etapas. El README distingue estos aportes del trabajo de backend/ML y seguidor solar de mis compañeros.

El repositorio incluye fotografías del prototipo, documentación bilingüe, una demostración local de software y pruebas de regresión Python/JavaScript posteriores a la defensa. El prototipo físico original se desmanteló después de presentarlo.
